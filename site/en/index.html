Install Nyx

You’ll need desktop Chrome and a NyxID account.

  1. Download and unzip

    Extract nyx-chrome-extension.zip and find the folder containing manifest.json.

  2. Load the extension in Chrome

    Open the address below, turn on Developer mode, select Load unpacked, and choose the extracted folder.

    chrome://extensions/

  3. Connect your NyxID

    Click Nyx in the Extensions menu, then select Connect to NyxID. Match the code on the authorization page, approve the services, and return to the panel to chat. Use the language selector in the panel header to follow Chrome or choose English or Simplified Chinese.

  4. Make a voice call

    Keep “Include voice calls” selected before connecting and authorize your OpenAI API connection (llm-openai) in NyxID. With an empty message box, choose “Voice call” and allow microphone access in Chrome. If Chrome denies the request, open “Microphone access”, allow it in the new tab, and return to the panel to call again. You can read captions, mute, or hang up to return to chat. Upgrading from 0.3.0 requires a new voice grant. Clear the checkbox before connecting to use your previous text grant.

Developer resources

The extension uses Manifest V3 and the Nyx Assistant SDK for chat and authorization.

Let Nyx call your website API

Add this script to your top-level page, or run it when a visitor enables your Nyx integration. This page runs the example below. Its callback fetches the version of the extension available for download.

JavaScript

To try this with Nyx, click its toolbar icon on this page and connect to NyxID. Choose Website APIs, select get_release, then choose Enable selected APIs. Ask “Use get_release to tell me the published version and minimum Chrome version.” Switching tabs, navigation, closing the panel, or choosing Disable website APIs clears access.

Callback contract and limits

Use a unique operation name and describe what it reads or changes. Map each required argument to string, number, or boolean. Return a JSON value or a promise for one. Your callback runs in the page’s session, so your server still checks authorization and your site handles confirmation for consequential actions.

Declare up to 16 tools, each with up to 16 arguments. Names start with an ASCII letter and use letters, digits or underscores, up to 48 characters. Descriptions allow 512 characters, string arguments 2,048, and serialized results 32,768. Keep the whole declaration under 16,384 characters. After a 15-second timeout, check the outcome on the site before trying again.

What can Nyx read from a page?

Click the Nyx toolbar icon on the page, then select Attach page content. Using activeTab and scripting, the extension reads the selection or visible text in the top frame, skipping form fields and editors. Review and edit the excerpt, then select Use excerpt to share it with Nyx. You can remove or replace it during the conversation.

How are access and conversations stored?

Text chat uses llm-nyx and chrono-llm-public. Voice also uses llm-openai. The extension encrypts the child credential in its own storage. Select Disconnect to revoke it. Closing the side panel ends the current conversation.
