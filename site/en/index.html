Install Nyx

You’ll need desktop Chrome and a NyxID account.

  1. Download and unzip

    Extract nyx-chrome-extension.zip and find the folder containing manifest.json.

  2. Load the extension in Chrome

    Open the address below, turn on Developer mode, select Load unpacked, and choose the extracted folder.

    chrome://extensions/

  3. Connect your NyxID

    Click Nyx in the Extensions menu, then select 连接 NyxID (Connect NyxID). Match the code on the authorization page, approve the services, and return to the panel to chat.

Developer resources

The extension uses Manifest V3 and the Nyx Assistant SDK for chat and authorization.

Run from source

Clone the repository and load the extension/ directory in Chrome. It runs directly from the checkout.

What can Nyx read from a page?

The extension requests access to the side panel and the NyxID API origin. To discuss a page, paste the text you choose into a message.

How are access and conversations stored?

NyxID grants access to llm-nyx and chrono-llm-public. The extension encrypts the child credential in its own storage. Select 断开授权 (Disconnect) to revoke it. Closing the side panel ends the current conversation.
