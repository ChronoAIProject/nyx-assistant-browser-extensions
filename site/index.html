Chrome 侧边栏扩展

Nyx for
Chrome.

在网页旁打开 Nyx 助手。切换标签页、刷新页面，都能在同一窗口继续对话。

↓下载 Chrome 扩展 GitHub ↗

桌面版 Chrome 116+ · Manifest V3

安装与使用

准备桌面版 Chrome 和一个 NyxID 账号。

  1. 下载并解压

    解压nyx-chrome-extension.zip，找到含 manifest.json 的文件夹。

  2. 在 Chrome 中加载扩展

    在地址栏打开下方地址，启用「开发者模式」，点击「加载已解压的扩展程序」并选择刚才的文件夹。

    chrome://extensions/

  3. 连接 NyxID，开始对话

    点击工具栏的 Nyx 图标，选择「连接 NyxID」，在授权页核对验证码并批准服务。回到侧边栏即可提问。

开发者资源

扩展使用 Manifest V3，聊天与授权由 Nyx Assistant SDK 提供。

从源码运行

克隆仓库，然后在 Chrome 中加载 extension/ 目录。源码可直接运行。

扩展会读取哪些网页数据？

扩展申请侧边栏和 NyxID API 站点权限。若要讨论正在浏览的内容，请把选定文字粘贴到对话中。

授权和会话如何保存？

NyxID 授权使用 llm-nyx 和 chrono-llm-public 服务。子凭据在扩展来源加密保存，可在侧边栏点击「断开授权」撤销。关闭侧边栏会结束本次对话。
