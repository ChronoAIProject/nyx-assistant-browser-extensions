Chrome 侧边栏扩展

在网页旁打开 Nyx 助手。切换标签页、刷新页面，都能在同一窗口继续对话。

桌面版 Chrome 116+ · Manifest V3

安装与使用

准备桌面版 Chrome 和一个 NyxID 账号。

  1. 下载并解压

    解压nyx-chrome-extension.zip，找到含 manifest.json 的文件夹。

  2. 在 Chrome 中加载扩展

    在地址栏打开下方地址，启用「开发者模式」，点击「加载已解压的扩展程序」并选择刚才的文件夹。

    chrome://extensions/

  3. 连接 NyxID，开始对话

    点击工具栏的 Nyx 图标，选择「连接 NyxID」，在授权页核对验证码并批准服务。回到侧边栏即可提问。 侧边栏顶部可选择跟随 Chrome、简体中文或 English。

  4. 与 Nyx 语音通话

    连接前勾选「启用语音通话」，在 NyxID 授权自己的 OpenAI API 连接（llm-openai）。输入框为空时点击「语音通话」，允许 Chrome 使用麦克风。若提示权限不足，打开「麦克风权限」，在新标签页允许后返回重拨。通话中可看字幕、静音或挂断。由 0.3.0 升级的用户首次使用语音需重新授权，连接前取消勾选即可使用原有文字授权。

让 Nyx 调用你的网站 API

把这段脚本放进顶层页面，也可以在访客开启网站的 Nyx 接入选项时执行。此页已运行下方示例，回调会查询当前可下载的扩展版本。

JavaScript

要在 Nyx 中试用，请在此页点击工具栏的 Nyx 图标并连接 NyxID。选择「网站 API」，勾选 get_release，点击「启用所选 API」。然后提问「请调用 get_release，告诉我已发布的版本及最低 Chrome 版本」。切换标签页、页面导航、关闭侧边栏或点击「停用网站 API」都会结束授权。

回调约定及限制

为每个操作取唯一的名称，说明它会读取或修改什么。用 string、number 或 boolean 声明每个必填参数。回调返回 JSON 值或对应的 Promise。它使用网页自身的登录身份，服务端仍需校验权限，涉及重要变更时由网站确认。

最多登记 16 个操作，每个最多 16 个参数。名称以英文字母开头，只含英文字母、数字或下划线，最多 48 个字符。描述最多 512 字符，字符串参数最多 2,048 字符，序列化结果最多 32,768 字符，整份声明限 16,384 字符。调用超过 15 秒时，请先在网站上核对结果。

扩展会读取哪些网页数据？

在要讨论的网页上点击工具栏的 Nyx 图标，然后选择「附上网页内容」。扩展使用 activeTab 和 scripting 临时读取顶层网页的选区或正文，跳过输入框与可编辑区域。预览、删改并确认后，Nyx 即可读取这份摘录。可随时移除或换一份摘录。

授权和会话如何保存？

文字聊天使用 llm-nyx 和 chrono-llm-public，语音还需要 llm-openai。子凭据在扩展来源加密保存，可在侧边栏点击「断开授权」撤销。关闭侧边栏会结束本次对话。
